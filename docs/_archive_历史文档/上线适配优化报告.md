## 三、弱网处理

### 3.1 网络请求优化

**新增功能**（[utils/request.js](file:///Users/huxiao/Public/测试项目-1-26.6.27/utils/request.js)）：
- **超时设置**：10秒（TIMEOUT_MS = 10000）
- **自动重试**：最多2次，间隔1秒
- **网络错误识别**：检测 timeout / network / request:fail 错误类型
- **友好提示**：失败时返回「网络连接失败，请检查网络后重试」

### 3.2 错误处理增强

```javascript
// 网络错误识别函数
function isNetworkError(err) {
  const errMsg = err.errMsg || err.message || '';
  return errMsg.indexOf('timeout') > -1 ||
         errMsg.indexOf('network') > -1 ||
         errMsg.indexOf('request:fail') > -1;
}

// 自动重试机制
if (isNetworkError(err) && retryCount < MAX_RETRY_COUNT) {
  setTimeout(() => {
    requestWithRetry(options, retryCount + 1)...
  }, RETRY_DELAY);
}
```

## 四、真机兼容性校验

### 4.1 安全区域适配

**适配覆盖率**：26处使用 safe-area-inset

| 类型 | 文件数 | 说明 |
|------|--------|------|
| 全局适配 | [app.wxss](file:///Users/huxiao/Public/测试项目-1-26.6.27/app.wxss#L8-L23) | page + 工具类 |
| 底部固定按钮 | 7个页面 | calc(XXrpx + env(safe-area-inset-bottom)) |
| 顶部状态栏 | 10个页面 | statusBarHeight + safe-area-inset-top |

**兼容性**：
- iOS：支持 `env(safe-area-inset-bottom)`（iOS 11.2+）
- Android：不支持 safe-area，但使用固定值 fallback
- 鸿蒙：兼容 iOS 模式，safe-area 有效

### 4.2 iOS/Android 差异处理

| 差异点 | 处理方式 |
|--------|---------|
| 状态栏高度 | 使用 `wx.getWindowInfo().statusBarHeight` 动态获取 |
| 底部安全区 | 使用 `constant()` + `env()` 双写兼容 iOS 11.0-11.2 |
| 1px 边框 | 保留 1px 用于 hairline，不转换为 rpx |

### 4.3 scroll-view 优化建议

当前 scroll-view 仅设置 `scroll-x` / `scroll-y`。建议后续版本添加：
- `enhanced="true"`（增强模式，2.12.0+）
- `bounces="false"`（禁用回弹，提升性能）
