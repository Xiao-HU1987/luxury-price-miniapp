# 数据库与接口规范

## 1. 云数据库集合 (Collections)
### products (商品主数据)
- productId (String): 唯一货号
- nameCn (String): 中文名称
- nameEn (String): 英文名称
- mainImage (String): 主图URL
- cnOfficialPrice (Number): 中国官网含税价
- category (String): 分类
- createTime (Date): 录入时间

### price_stock (价格与库存动态)
- productId (String): 关联货号
- countryCode (String): 国家代码
- localPrice (Number): 当地原价
- currency (String): 货币代码
- cnyPrice (Number): 折算人民币
- stockStatus (String): available / out_of_stock
- storeInfo (Object): { city, storeName, address }
- firstCreateTime (Date): 首次录入时间
- priceUpdateTime (Date): 价格更新时间
- evidence (Object): { screenshotUrl, captureTime } (爬虫截图留证)

### exchange_rates (汇率与渠道)
- currency (String): 外币代码
- baseRate (Number): 基础汇率
- channels (Array): 包含 tieredRules 数组 [{minAmount, discountRate, description}]

### user_favorites (用户数据)
- openid (String): 微信OpenID
- favorites (Array): 收藏货号列表
- viewHistory (Array): 浏览历史
- calcHistory (Array): 计算历史
- settings (Object): { defaultCurrency, enableNotify }

## 2. 云函数接口 (API)
- getProductList: 入参 {keyword, page, pageSize} -> 返回含 bestGlobalPrice 的列表
- getProductDetail: 入参 {productId} -> 返回详情、置顶最优价、过滤后的日韩库存
- calculateFinalPrice: 入参 {productId, countryCode, taxRefundRate, rebateRate, channelCode, totalAmount} -> 返回最终人民币到手价及明细
- getExchangeRates: 返回汇率与阶梯规则
- userAction: 入参 {actionType, productId?, settings?} -> 统一处理收藏/设置等
