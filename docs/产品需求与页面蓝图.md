# LV全球比价与到手价助手 - 页面模块蓝图

## Tab 1：比价首页 (Index Page)
- 顶部：SearchBar（浅灰背景，支持货号/名称搜索）。
- 热门横向滚动区：Horizontal Scroll + Card（主图、中英文名、货号、中国官网价Tag[中]、全球最优价Tag[如:日/法]）。
- 全部商品列表：List + Card + Skeleton（同上卡片元素 + 底部小字提示“到手价实时更新”）。
- 底部：Empty 空状态 / Loading 触底加载。

## Tab 2：到手价计算器 (Calculator Page)
- 顶部：Input（原价）+ Picker（币种）。
- 优惠叠加区：Slider/Stepper（退税、返点比例）+ Picker（支付渠道）。
- 结果展示：Card 展示最终到手价（醒目红 #E53935 大字），折叠面板展示计算明细。全页面毫秒级实时联动。
- 底部：FloatingButton（一键保存/分享海报）。

## Tab 3：综合工具页 (Tools Page)
- 顶部：Tabs 切换（汇率看板 / 返点优惠）。
- 汇率看板：Input 换算器 + List（渠道名称、当前汇率、阶梯折扣说明、更新时间）。
- 返点优惠：Banner（热门活动）+ List（商家、返点比例、适用条件）。

## Tab 4：我的 (Profile Page)
- 顶部：Avatar + 微信昵称。
- 菜单列表：我的收藏、商品浏览历史、计算历史记录、消息提醒（Switch）、默认货币（Picker）、关于我们/意见反馈。

## 核心子页面：商品详情页 (Detail Page)
- 顶部：商品主图（不可放大）+ 右上角收藏按钮（空心/实心切换）。
- 信息：中英文名称、货号、中国大陆官网含税价。
- 全球价格对比：List（国家、折算人民币、省钱金额）。最优价自动置顶并高亮（活力橙）。每项右侧带“计算到手价”入口。
- 门店库存（本期仅日韩）：Tabs/Picker 切换国家。有库存显示城市、门店名、地址；无库存完全隐藏。
